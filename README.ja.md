# Handheld Matrix — ハンドヘルド比較ダッシュボード

純フロントエンドのハンドヘルドゲーム機比較ダッシュボードです。人気機 8 台の詳細スペックを内蔵し、予算・重量・バッテリー持ち・画面の好みから最適な 1 台を選べます。

**使い方：** `index.html` を開くだけ。ビルドもアカウントも不要で、計算と描画はすべてブラウザ内で完結します。

## 機能

- **多次元スペックカード**：価格・重量・バッテリー・画面（サイズ／タイプ／リフレッシュレート／解像度／色域）・ハードウェア構成を一画面で確認
- **あいまい検索**：Fuse.js による検索、別名（SD、Deck など）にも対応
- **スライダーフィルター**：nouislider で価格や主要スペックを絞り込み
- **可視化**：Chart.js チャートとレーダー比較パネル
- **MATRIX COMPARE**：複数機種を選んで並べて比較
- **ポスター書き出し**：html2canvas で比較結果を PNG として書き出し
- **細部**：カードの 3D チルト + グレア（vanilla-tilt）、Lucide アイコン、ダーク／ライトテーマ

## データ

デバイスのスペックは `devices.json` に保存されています。新しい機種を追加するには、エントリを 1 つ追記するだけでページが自動的に読み込みます。
